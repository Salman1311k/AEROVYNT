# Super Intelligence (SI) disclosure

**Team:** Muhammad Salman and Sayed Hamza

AEROVYNT was built by the team above with assistance from **Claude (Anthropic)**, a large language model, used as a coding and writing assistant.

**Where SI was used**
- Code: the JavaScript, HTML and CSS for the website and Co-Pilot, and the Python research code, were written, debugged or refactored with SI assistance. Every code file carries a header comment saying so.
- Data processing: the scripts that build the cached benchmark and data tables (research/, assets/data.js) were SI-assisted. The numbers come from running that code on the NASA OSD-575 and PMData files, not from SI.
- Text: page copy, the Evidence and limitations wording and the project-page text were drafted or edited with SI assistance and reviewed by the team.
- Body map, camera pulse, guided demo and evidence-ladder code were written with SI assistance. The camera algorithm was tested only on synthetic signals generated by code; it has not been tested on people.

**Where SI was not used**
- SI is not used at run time: the app is plain JavaScript that runs locally in the browser.
- No NASA logos, flags or mission identifiers are used or modified.
- No reviewer, quote or feedback in this project was written by SI. `assets/reviews.js` is empty because no clinician or expert has reviewed the project yet.
- The app icon (assets/icon.svg and its PNG versions) is a simple vector shape written as code; it is not a generated photo or artwork. No SI-generated photos, video or audio are included.

**Human role**
Muhammad Salman and Sayed Hamza chose the problem and approach, selected the datasets, reviewed the results and wording, and take responsibility for the claims made. The project idea, the demo video and the other submission materials are the team's own work.

**Known limits (stated on the Evidence page)**
- Headline detection results are simulated; the engine's thresholds were set on the same simulator.
- Real data (PMData, OSD-575) has no illness labels, so it checks noise and false alarms, not detection.
- No clinical review and no test of the camera pulse on people.

Data sources: NASA OSDR OSD-575 (Inspiration4); PMData (Thambawita et al. 2020, CC BY 4.0).
